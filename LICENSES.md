## 2. Typography

The SVG assets use modern system sans-serif font stacks:
```css
font-family: system-ui, -apple-system, 'Segoe UI', Roboto, Helvetica, Arial, sans-serif;
```
- **Rationale:** Ensures 100% native rendering fidelity across macOS, iOS, Windows, Android, and Linux without requiring external web font downloads, avoiding `@font-face` network latency, privacy blocks, or GitHub Camo proxy failures.
- **License:** Native OS and platform fonts provided by the respective operating system vendors.
