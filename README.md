## 🚀 What I'm Building

### 👗 OutRenz

A peer-to-peer clothing rental marketplace built around a simple idea:

> **Why buy an outfit you'll only wear once?**

OutRenz connects people who want to rent clothes with people who want to monetize clothes sitting unused in their wardrobes.

**Highlights**

* 🛍️ Clothing marketplace
* 👤 Peer-to-peer listings
* 📦 Rental lifecycle management
* 💰 Pricing, deposits & payouts
* 📏 SmartFit sizing experience
* 🧼 Hygiene & quality workflow
* 🔐 Trust & safety mechanisms

🌐 **[Visit OutRenz](https://outrenz.in)**
📂 **[OutRenz Showcase](https://github.com/Dhyan-Doshi/OutRenz)**

> Production source code is private because OutRenz is an active product.
